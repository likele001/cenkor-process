# 贡献者许可协议（CLA）

> 本文件为模板，签署前须经法务审核；不构成法律意见。
> 适用项目：CenkorProcess（流程制造引擎），核心以 AGPL-3.0 开源，项目方保留商业授权权利。

## 1. 定义

- **项目方**：CenkorProcess 的著作权人及其指定的管理主体。
- **贡献者**：向本项目提交代码、文档、设计或其他材料的自然人、法人或组织。
- **贡献**：贡献者以 Pull Request、补丁、Issue 附件、邮件等任何形式提交给本项目的全部内容。

## 2. 版权许可

贡献者授予项目方一项**永久的、全球范围的、非独占的、免版税的、不可撤销的**版权许可，允许项目方：

1. 以 AGPL-3.0 或项目方届时选择的其它开源许可证分发贡献；
2. 以商业许可方式分发、修改、再许可包含贡献的作品；
3. 对贡献进行修改、改编、组合，并用于与本项目相关的任何目的。

贡献者保留其贡献的著作权，本协议不构成著作权转让。

## 3. 专利许可

贡献者授予项目方及其用户一项永久的、全球范围的、免版税的、不可撤销的专利许可，用于实施包含贡献的作品。若贡献者就本项目提起专利诉讼，本条款授予的专利许可自起诉之日起终止。

## 4. 陈述与保证

贡献者声明并保证：

1. 其有权授予上述许可，贡献不侵犯任何第三方的著作权、专利权、商标权或商业秘密；
2. 若贡献包含第三方材料，已在提交时明确标注来源与许可证，且该许可证与本协议不冲突；
3. 贡献为其原创，或已获得原权利人充分授权。

## 5. 无义务采纳

项目方没有义务采纳任何贡献；是否合并、修改或删除由项目方自行决定。

## 6. 生效方式

贡献者通过以下任一方式表示接受本协议：

1. 在 Pull Request 描述中写明：`I have read and agree to the CLA in docs/CLA.md.`；
2. 签署单独的书面 CLA 并提交至项目方指定邮箱。

## 7. 其他

本协议适用中华人民共和国法律。条款若被认定无效或不可执行，不影响其余条款的效力。
